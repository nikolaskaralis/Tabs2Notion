Tabs2Notion Help

How saving works

Choose a tab command from the toolbar popup or context menu. Tabs2Notion captures the matching tab titles and URLs, then opens a small destination window. Pick a connected workspace, search for a Notion database, and save.

Tabs2Notion always preserves the original URL in the created page. When it can identify a URL property in the target data source schema, it fills that property too.

Notion sign-in

Tabs2Notion uses Notion's hosted MCP OAuth flow with PKCE and dynamic client registration. Authentication happens directly between this extension and Notion; there is no Tabs2Notion authentication backend and no API key to paste.

Access and refresh tokens are encrypted locally in the Chrome profile. Disconnecting a workspace removes the stored credentials for it.

Finding a database

Recent destinations appear immediately. For a new destination, type part of its name into the search field. Notion MCP search is used on demand rather than downloading a full list of every page in the workspace.

If a search result is not actually a database, Tabs2Notion will reject it before writing anything and ask you to choose a database/data source.

Tab-selection commands

Current window: every sendable tab in the active window. Current group: tabs sharing the active tab's Chrome group. Selected: Chrome-highlighted tabs. Left/right: tabs relative to the active tab. All windows: every sendable open tab.

Chrome internal pages such as chrome:// URLs are skipped. Excluded domains are also skipped. Tabs are only closed if you explicitly enable “Close successfully saved tabs” in the destination window.
