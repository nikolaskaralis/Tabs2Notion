Tabs2Notion Help

How saving works

Choose a tab command from the toolbar popup or context menu. Tabs2Notion captures the matching tab titles and URLs, then opens a small destination window. Pick a connected workspace and an accessible Notion database, then save.

If the target database contains a URL property, Tabs2Notion writes the tab URL there. Otherwise it preserves the URL as a clickable link inside the new Notion page.

OAuth backend setup

Notion public OAuth requires a client ID and client secret when exchanging authorization codes. A browser extension cannot safely contain that secret, so Tabs2Notion includes a minimal Cloudflare Worker under backend/cloudflare-worker.

Follow the repository README to create a Notion public connection, deploy the Worker, set its secrets, register the Worker callback URL in Notion, then paste the Worker URL into Tabs2Notion settings.

Workspace/database access

During Notion OAuth, Notion shows a page picker. Only pages/databases you grant to Tabs2Notion are returned by the Notion Search API. If a database is missing, reconnect the workspace and grant access to that database or a parent page containing it.

Tab-selection commands

Current window: every sendable tab in the active window. Current group: tabs sharing the active tab's Chrome group. Selected: Chrome-highlighted tabs. Left/right: tabs relative to the active tab. All windows: every sendable open tab.

Chrome internal pages such as chrome:// URLs are skipped. Excluded domains are also skipped. Tabs are only closed if you explicitly enable “Close successfully saved tabs” in the destination window.
