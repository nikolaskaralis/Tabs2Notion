Tabs2Notion Help

How saving works

Choose a tab command from the toolbar popup or context menu. Tabs2Notion captures the matching tab titles and URLs, then either saves immediately using your configured defaults or opens a small destination window. Pick a connected workspace and an accessible Notion database, then save.

If the target database contains a URL property, Tabs2Notion writes the tab URL there. Otherwise it preserves the URL as a clickable link inside the new Notion page.

Notion connection

Tabs2Notion uses Notion public OAuth. The release build already knows the publisher-hosted authentication service, so normal users only need to click Connect Notion. No Worker URL, API token, or client secret needs to be entered.

Workspace/database access

During Notion OAuth, Notion shows a page picker. Only pages/databases you grant to Tabs2Notion are returned by the Notion Search API. If a database is missing, reconnect the workspace and grant access to that database or a parent page containing it.

Defaults

In Settings you can choose a default workspace/database, whether successfully saved tabs should close, whether actions should skip the destination dialog, and what happens when you click the pinned Tabs2Notion icon.

Tab-selection commands

Current window: every sendable tab in the active window. Current group: tabs sharing the active tab's Chrome group. Selected: Chrome-highlighted tabs. Left/right: tabs relative to the active tab. All windows: every sendable open tab.

Chrome internal pages such as chrome:// URLs are skipped. Excluded domains are also skipped. Tabs are only closed according to your configured close-tabs behavior.
