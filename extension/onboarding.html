iHow it works
If instant saving is enabled, the chosen action saves tabs right away using the default workspace and database. Otherwise, Tabs2Notion opens the destination picker so you can choose where to save.

How to use Tabs2Notion

1

Connect Notion

Authorize Tabs2Notion to access the Notion workspace(s) and databases you want to use.

2

Choose tabs or windows

Use the pinned icon or the flat right-click menu to choose which tabs you want to send.

3

Save instantly or review

Use defaults for one-click saving, or open the selector to choose the destination before sending.
