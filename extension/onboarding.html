Tabs2Notion

Send open tabs straight to Notion.

Tabs2Notion uses Notion OAuth. Your Notion password is entered only on Notion's own authorization page; the extension never receives it.

1. OAuth backend

A tiny companion backend is required because Notion's OAuth token exchange requires a client secret, which cannot safely be embedded in a Chrome extension.

Setup instructions

2. Connect Notion

Connect one or more workspaces. You choose which pages/databases Tabs2Notion may access in Notion's page picker.

3. Use it

Click the Tabs2Notion toolbar icon, or right-click the extension/page/tab and choose a tab-selection command. A small destination window opens so you can choose the workspace and Notion database before saving.
