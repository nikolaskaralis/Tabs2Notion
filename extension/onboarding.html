Tabs2Notion

Send open tabs straight to Notion.

Tabs2Notion uses Notion OAuth. Your Notion password is entered only on Notion's own authorization page; the extension never receives it.

Developer setup

This unpacked development build does not have a production OAuth backend configured yet. Enter the publisher's OAuth Worker URL below. This section is hidden in a release build with a bundled backend URL.

Developer setup instructions

Connect Notion

Connect one or more workspaces. You choose which pages and databases Tabs2Notion may access in Notion's authorization flow.

Use it

Click the Tabs2Notion toolbar icon, or right-click the extension/page/tab and choose a tab-selection command. A small destination window opens so you can choose the workspace and Notion database before saving.
