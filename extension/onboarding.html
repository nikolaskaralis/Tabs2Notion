Developer setup

This unpacked development build does not have a production OAuth backend configured yet. Enter the publisher's OAuth Worker URL below. This section is hidden in a release build with a bundled backend URL.

Developer setup instructions

Notion connection

Connect one or more workspaces. You choose which pages and databases Tabs2Notion may access during Notion authorization.

Defaults

Choose a default destination and behavior. When instant saving is enabled, actions skip the destination window entirely.

Use it

Use the pinned icon or the flat right-click menu. If instant saving is disabled, Tabs2Notion opens the destination picker for each action.
