# Chrome Web Store assets

Prepared production assets:

- `store-icon-128.png` — 128×128 PNG; the visible icon is approximately 96×96 with transparent padding for the Chrome Web Store.
- `promo-440x280.png` — required small promotional tile.
- `marquee-1400x560.png` — optional marquee promotional tile.

The four runtime extension icons live in `extension/icons/` and are separately tuned for 16, 32, 48, and 128 px use.

Real screenshots should be captured from the final browser build after smoke testing; see `CHROME_WEB_STORE.md` for the recommended five-shot set and required dimensions.
